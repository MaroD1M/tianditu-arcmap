# 技术手册（tianditu-arcmap）

面向**维护者 / 二次开发者**。说明本工具的架构、模块职责、关键机制、
配置结构、线程与生命周期模型，以及扩展方式。

- 面向普通用户的操作步骤见 [使用说明](使用说明.md)。
- 打包发布见 [打包说明](打包说明.md)。
- 项目总览见 [README](../README.md)。

---

## 一、概述

`tianditu-arcmap` 在本机启动一个**轻量瓦片代理服务**，把天地图（国家地理信息
公共服务平台）的 WMTS 瓦片转发给 ArcMap，并在转发过程中完成：

- **多密钥轮换**：按当日用量挑选「启用且未超额、用量最低」的密钥注入请求；
- **本地缓存**：按真实图片类型落盘，跨会话复用，节省密钥配额；
- **能力文档改写**：把 GetCapabilities 返回里的天地图子域改写成 `localhost`，
  让 ArcMap 后续的瓦片请求也走本地代理；
- **可视化配置**：图形界面管理密钥、端口、缓存、底图，无需手改 JSON。

设计约束（重要）：

1. **运行期零第三方依赖**，只用 Python 标准库（`tkinter` / `http.server` /
   `http.client` / `json` / `threading` / `ctypes`）。这是硬性目标，新增功能
   不得引入 pip 依赖。
2. **可打包为单文件 exe**。`frozen` 时路径全部基于 `sys.executable` 所在目录
   （见 `utils.app_base_dir`）。
3. **退出必须干净**，不留下「窗口关了但进程还在」的残留（见第六节）。

## 四、架构总览

```
                 ┌──────────────────────────────────────────────┐
   ArcMap ──────▶│  本地 HTTP 服务  http_server.ProxyHTTPServer  │
  (WMTS 客户端)   │  · 有界线程池(64) · 连接跟踪                  │
                 └───────────────┬──────────────────────────────┘
                                 │ ProxyHandler._serve()
                                 ▼
                 ┌──────────────────────────────────────────────┐
                 │  proxy.TileProxy.handle_request(path, query)  │
                 │   1) 解析图层 / 请求类型                       │
                 │   2) 生成缓存键 → 命中则直接返回                │
                 │   3) 选密钥(get_active_token)                  │
                 │   4) 子域轮换(t0..t7) → 连接池取连接            │
                 │   5) 转发上游，写缓存、计数                      │
                 └───────┬───────────────────────┬──────────────┘
                         │ ConnPool              │ Cache(mem+disk)
                         ▼                       ▼
              t*.tianditu.gov.cn            缓存目录/图层/z/y/x.ext

   界面(gui.App) ──持有──▶ TileProxy，并轮询其 stats / 日志队列刷新 UI
   config.load/save ──读写──▶ config.json（与 proxy 共享同一个 dict）
```

**数据流要点**：`App` 与 `TileProxy` 共享同一个配置字典对象，界面上的任何
修改都**就地写回**该 dict，因此代理能立刻看到新设置（见 `gui._sync_config`）。

## 五、模块详解

### constants.py
纯静态数据，不依赖任何其它模块：应用信息、底图分组 `LAYER_GROUPS` 与扁平索引
`LAYERS`、默认底图 `DEFAULT_LAYERS`、子域 `SUBDOMAINS`（t0~t7）、
默认配置 `DEFAULT_CONFIG`、内置帮助文本 `HELP_TEXT`。

- `LAYERS` 是「图层键 → 中文说明」的映射，`proxy` 用它判断 URL 里的图层段。

### utils.py
- `human_size(n)`：字节数格式化。
- `parse_qs_ci(query)` / `qget` / `build_upstream_query`：**大小写不敏感**的
  query 解析与还原。ArcMap 发的是 `TileMatrix/TileRow/TileCol`（驼峰），标准
  WMTS 是全大写；`urllib.parse.parse_qs` 区分大小写，直接用会读空，导致瓦片请求
  被误判、缓存永不生效。`_raw` 保留客户端原始大小写，转发上游时按原样发回。
- `app_base_dir()` / `default_config_path()`：路径解析，区分 `frozen`（exe）。
- `port_available(port)` / `find_free_port(...)`：端口检测。Windows 用
  `SO_EXCLUSIVEADDRUSE`（`SO_REUSEADDR` 会「抢占」已占用端口，造成误判），
  并先做一次 TCP 连接探测。
- `set_autostart` / `get_autostart` / `autostart_supported`：写/读
  `HKCU\...\Run` 自启项；`winreg is None`（非 Windows）时安全降级。
- `enable_dpi_awareness()`：在创建 Tk 窗口前调用，失败静默忽略。

### config.py
`load_config` / `save_config`。加载时对旧配置做**向前兼容**：单个 `token`
字段迁移为 `tokens` 列表、过滤未知图层、修正类型。保存时只写持久化字段。

### proxy.py —— 核心
两个类：

**`ConnPool`**：按 `(scheme, host)` 复用 HTTP 连接（每主机最多 8 条空闲）。
天地图请求量大，复用连接可省去重复 TCP/TLS 握手，显著提速。

**`TileProxy`**：
- 生命周期：`start()` 绑定 `127.0.0.1`（`local_only=True`）或 `0.0.0.0`，
  起 `ProxyHTTPServer`；`stop()` 关闭并断开连接。
- 密钥选择 `get_active_token()`：在启用密钥中优先取「未超额」的子集，再按
  `used` 升序取最小；`count_token()` 每次成功取瓦片后 +1。`used` 为**进程内**
  统计，启动时 `_reset_usage()` 归零。
- 子域轮换 `next_subdomain()`：`t0..t7` 轮询，分散单域压力。
- 缓存：见第七节。
- 请求路由 `handle_request()`：
  1. 从路径中找已知图层段；找不到返回 404。
  2. 取 `REQUEST` 参数；若 URL 形如 `.../WMTSCapabilities.xml` 也判为
     `GETCAPABILITIES`（ArcMap 会试探 REST 风格地址）。
  3. 上游子路径：
     - 瓦片请求（`GetTile` 或同时带 `TILEMATRIX/TILEROW/TILECOL`）→ `wmts`
       （esri 接口只出能力文档，不提供瓦片）；
     - `GetCapabilities` → `esri/wmts`（`mode=esri`）或 `wmts`，并强制用规范
       KVP 参数；
     - 其它带剩余路径的 → 原样透传。
  4. 无可用密钥 → 403；命中缓存 → 直接返回；否则转发上游。
  5. `GetCapabilities` 返回体做子域改写；瓦片请求写缓存并计数。
- `rewrite_capabilities()`：把 `t[0-7].tianditu.gov.cn` 正则替换为
  `localhost[:port]`，使 ArcMap 拿到的能力文档指向本地代理。
- `test_token(token, layer="img_w")`：请求一张真实瓦片，依据 HTTP 状态与
  JPEG 魔数 `\xff\xd8` 判断密钥是否有效。
- **请求头注意**：转发时不要自定义 `User-Agent`/`Referer`，否则可能被天地图
  WAF 拦截返回 403。

### http_server.py
- `ProxyHTTPServer(ThreadingHTTPServer)`：
  - **有界线程池**（默认 64），避免 ArcMap 并发时线程爆炸。

    注意**不要**试图在 `start()` 之后把 worker 改成 daemon（会抛
    `RuntimeError`）；而且 `concurrent.futures` 的 atexit 钩子会无条件
    join 所有 worker，daemon 属性也挡不住。退出安全由
    `TileProxy.stop()` 断开在途连接 + GUI 的 `_force_exit()` 兜底保证。
  - **连接跟踪**：记录所有活跃客户端连接，`shutdown_all_conns()` 主动断开，
    避免停止服务时干等 keep-alive 超时（最长 65 秒）。
  - `server_close()`：先断连接 → `executor.shutdown(wait=False)` → 不再阻塞；
    `wait_closed()` 供退出流程在后台等待线程池收尾。
- `ProxyHandler(BaseHTTPRequestHandler)`：HTTP/1.1 + keep-alive；`/` 返回状态页；
  其余交给 `proxy.handle_request`；默认逐请求日志被丢弃（统计走计数器），
  只保留错误日志；CORS 头按 `local_only` 决定放开范围。

### tray.py
纯 `ctypes` 实现的 Windows 系统托盘（`Shell_NotifyIconW` + 隐藏窗口消息循环）。
设计上**托盘永远是可选的**：任何失败都不得让程序打不开主界面，失败时降级为
「任务栏最小化 + 关闭二次确认」。线程与主线程通过队列通信，避免跨线程操作 UI。

### theme.py
界面主题。集中定义配色常量与 ttk 样式，并自绘复选框指示器：
- 由于程序使用 `clam` 主题时选中态被画成 `×`，这里用 base64 PNG 自建
  `Modern.TCheckbutton` element（18/24/36 三档，按 `tk scaling` 选择）。
- **注意**：`PhotoImage` 必须保存在模块级 `_IMG_REFS` 里，否则会被 GC 回收，
  导致指示器突然消失（历史 bug）。

### table.py
`GridTable`：`Canvas + Frame` 自绘表格，支持列分隔竖线、隔行底色、选中高亮、
纵向滚动、按权重自适应列宽、`set_cell` 局部刷新。之所以不用 `ttk.Treeview`，
是因为 Treeview 无法绘制单元格/列边框。表头标签设 `width=1` 以保证表头与表体
列宽一致。

### gui.py
`App(tk.Tk)`：主窗口 + 四个页签（服务与地址 / 密钥管理 / 底图选择 / 运行日志）。
- `_set_window_icon()`：设置窗口 / 任务栏图标，使其与托盘、exe 图标一致（`icon.ico`；
  冻结时用 exe 自带图标；非 Windows 回退 `icon.png`）。
- `_sync_config()`：把界面控件状态**就地**写回共享配置 dict，并做校验/联动。
- 周期任务 `_tick()`：刷新状态、统计、缓存信息，消费代理日志队列。
- 异步：缓存扫描/清理、密钥测试在后台线程执行，结果经队列回主线程。
- `_on_close()` / `_real_quit()` / `_force_exit()`：退出流程（见第六节）。

### tianditu_gui.py
启动入口，仅 `from gui import main`。文件头注释即项目概览。

## 六、生命周期与线程模型

线程构成：

1. **主线程（Tk）**：界面与事件循环；所有 UI 操作只能在此线程。
2. **HTTP accept 线程**：`serve_forever`，daemon。
3. **线程池工作线程**：处理请求，由 accept 线程创建（daemon）。
4. **托盘线程**：消息循环，daemon。
5. **一次性后台线程**：缓存扫描/清理、密钥测试、退出收尾，均 daemon。

**干净退出流程**（`_real_quit`）：

1. 停止 HTTP 服务（断开客户端连接与在途上游连接 + `server_close`，不阻塞 UI）；
2. 停止托盘线程并等待其真正结束；
3. 销毁主窗口；
4. 检查是否还有**任意残留线程**（不能只查非 daemon，原因见上节），
   1 秒内未退出则 `_force_exit` 强制结束进程。

这样即使 ArcMap 正在批量请求，也不会残留后台进程。

## 七、缓存机制

- **缓存键**：`(layer, TILEMATRIX, TILEROW, TILECOL)`。
- **内存缓存**：`mem_cache` 字典，上限 5000 条，超出时淘汰最早一半。
- **磁盘布局**：`<缓存目录>/<图层>/<z>/<y>/<x>.<ext>`（`x` 为列、`y` 为行），
  同目录另存 `x.<ext>.ctype` 记录 Content-Type。
- **扩展名**：按上游返回的 Content-Type 决定（`image/jpeg→.jpg`、
  `image/png→.png` 等，见 `CTYPE_EXT`）。读取时按文件名前缀匹配，因此能同时
  兼容新格式与旧版 `*.tile`（`LEGACY_EXT`）。
- **缓存目录**：相对路径按 `app_base_dir()` 解析为绝对路径。
- **安全校验** `cache_dir_danger()`：拒绝程序目录本身、盘符根、系统关键目录、
  以及包含程序目录的上级目录，防止清理时误删。
- **清理** `clean_cache()`：先删过期（mtime 早于 N 天），若仍超体积上限再按
  mtime 从旧到新删到上限内；`.ctype` 跟随其瓦片删除。程序启动时自动执行一次。
- **写失败**：只提示一次并给出缓存目录，避免刷屏。
- 切换缓存目录 / 开关缓存时须调用 `invalidate_mem_cache()`，否则旧目录数据仍在
  内存命中，新目录看似「不生效」。

## 八、配置结构（config.json）

位于程序目录（`default_config_path()`）。字段：

| 键 | 类型 | 默认 | 说明 |
|----|------|------|------|
| `port` | int | 80 | 本地服务端口 |
| `scheme` | str | `http` | 请求天地图所用协议（`http` / `https`） |
| `mode` | str | `esri` | 能力文档接口：`esri`（EPSG:3857 修正）/ `ogc` |
| `local_only` | bool | true | 仅监听 127.0.0.1 |
| `cache_enabled` | bool | true | 是否写磁盘缓存 |
| `cache_dir` | str | `cache` | 缓存目录（相对=程序目录下） |
| `cache_max_mb` | int | 1024 | 体积上限 MB，0=不限 |
| `cache_expire_days` | int | 30 | 过期天数，0=不过期 |
| `layers` | list[str] | `["img_w","img_c","vec_w","vec_c"]` | 启用的图层键 |
| `tokens` | list[obj] | `[]` | 密钥列表，见下 |
| `close_to_tray` | bool | true | 关闭窗口最小化到托盘 |
| `autostart` | bool | false | 开机自启 |
| `geometry` | str | "" | 上次窗口几何 |
| `verbose_log` | bool | false | 逐条瓦片日志（排障用） |

`tokens[]`：

| 键 | 说明 |
|----|------|
| `token` | 天地图密钥（tk） |
| `active` | 是否启用 |
| `limit` | 每日额度上限（0=不限） |
| `description` | 备注 |
| `used`（运行时） | 本次运行已用次数，不持久化 |

> 兼容性：旧版的单个 `token` 字段会在 `load_config` 时自动迁移为 `tokens`。

## 九、扩展指南

- **新增底图**：在 `constants.LAYER_GROUPS` 增条目即可，界面分组、URL 生成、
  图层校验都会自动生效。
- **新增接口模式**：改 `proxy.handle_request` 里 `upstream_suffix` 的分支。
- **新增主题**：在 `theme.py` 调整配色常量与 ttk 样式；复选框指示器按需替换
  base64 图标。
- **新增表格列**：调用 `GridTable(columns=[...])` 传入列定义（`key/label/width/
  weight/anchor/font`），用 `set_rows` / `set_cell` 更新数据。
- **新增界面页签**：在 `gui` 的 `_build_ui` 中注册，并在 `_tick` 中接入刷新。

修改后务必：`python -m compileall .`、`python -m pyflakes *.py`，并实际启动
`python tianditu_gui.py` 验证。

## 十一、已知约束

- 天地图免费账号每日约 1 万次请求，`limit` 用于轮换避限额。
- `used` 为进程内计数，重启归零；如需跨会话统计需自行扩展持久化。
- 托盘 / 开机自启 / 高 DPI 仅 Windows 生效；其它平台自动降级。
- `esri` 接口仅用于 GetCapabilities（分辨率已按 EPSG:3857 修正），瓦片走标准
  `wmts` 接口。
