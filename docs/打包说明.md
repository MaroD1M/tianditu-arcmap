# 打包说明（天地图 ArcMap 加载工具 v2）

把 `tianditu_gui.py` 打包成单个 Windows 可执行文件（exe），方便直接分发给别人使用。

> 本文所写路径（`build.bat`、`dist\`、`icon.ico` 等）均相对**项目根目录**
> （即 `tianditu_gui.py` 所在目录）。文档位于 `docs/`，实际文件在上一级目录。

## 一、准备工作

1. 一台 **Windows** 电脑。
2. 安装 **Python 3.8 或更高版本**（64 位）。
   - 官网：<https://www.python.org/downloads/>
   - 安装时务必勾选 **「Add Python to PATH」**。
   - Windows 官方安装包自带 `tkinter`，无需另外安装。
3. 本程序**运行期不需要任何第三方库**：
   托盘用 Windows 原生 API（`ctypes`）实现，缓存/代理用标准库
   （`http.server` / `http.client` / `json` / `threading`）。
   所以打包出来的 exe 体积小，也不会因为缺少依赖而报错。

## 二、打包步骤

1. 把整个文件夹复制到 Windows 电脑。
   （代码已按功能拆分为 `gui.py` / `theme.py` / `table.py` / `proxy.py` /
     `http_server.py` / `tray.py` / `config.py` / `utils.py` / `constants.py`，
     打包时全部会被自动收进 exe，请勿只拷贝单个文件。）
2. 双击运行 **`build.bat`**（自动安装 PyInstaller 并打包）。
3. 完成后，exe 位于 **`dist\天地图加载工具.exe`**。

把该 exe 单独拷给别人即可使用。首次运行会在 exe 同目录自动生成
`config.json`（配置）与 `cache\`（瓦片缓存）。

## 三、手动打包（可选）

```bat
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name "天地图加载工具" tianditu_gui.py
```

| 参数 | 作用 |
|------|------|
| `--onefile` | 打包成单个 exe |
| `--windowed` | 不弹黑色控制台窗口（纯图形界面） |
| `--name` | 输出文件名 |
| `--icon app.ico` | 可选：指定程序图标（同时托盘图标会复用它） |

### 图标

项目已自带 `icon.ico`（天地图官方橙色地球徽标，多尺寸 16~256），
`build.bat` 会自动识别并作为程序与托盘图标使用，无需额外操作。
`icon.png`（1024 像素）为生成 `icon.ico` 的源图，可留作重新生成用。

如需换图标，准备一个 `app.ico` 放在同目录即可（`app.ico` 优先级高于 `icon.ico`）。
托盘图标按以下顺序自动选择：

1. exe 自带图标（打包时用 `--icon` 指定过就会有）
2. exe 同目录下的 `icon.ico`
3. Windows 默认应用程序图标

## 四、常见问题

1. **杀毒软件误报**
   PyInstaller 打包的单文件 exe 常被误报，添加信任即可；
   或改用 `--onedir` 目录模式（不压缩为单文件，误报率更低）。

2. **端口 80 启动失败**
   Windows 下监听 80 端口需管理员权限，且可能被 IIS 占用。
   在界面里点「检测」换一个高位端口即可。

3. **托盘图标不显示 / 关闭后找不回窗口**
   确认系统托盘没有隐藏该图标（点任务栏的「显示隐藏的图标」）。
   即使托盘不可用，程序也会正常退出，不会卡住。

4. **双击 exe 没反应**
   确认目标系统是 64 位 Windows 10/11（绝大多数已自带所需运行库）。

5. **修改代码后重新打包**
   先删除 `build\`、`dist\` 和 `*.spec`，再重新运行 `build.bat`。
