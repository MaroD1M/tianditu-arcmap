# 使用说明（天地图 ArcMap 加载工具 v2）

把「天地图」在线底图（影像 / 矢量 / 注记 / 地形）加载到 ArcMap 中。
用图形界面管理密钥，代替原控制台程序手工填写配置的方式。

> 界面里也有同样的指引：菜单 **帮助 → 使用步骤 / 密钥申请**。
> 相关文档：[打包说明](打包说明.md) · [技术手册](技术手册.md) · [项目 README](../README.md)

---

## 一、界面结构

界面采用**现代扁平风格**：顶部是**主色蓝状态条**，下方四个页签用主色高亮当前页；
表格有**列分隔线**和**隔行底色**，便于横向对齐阅读；勾选框是清晰的蓝色「**√**」。

| 位置 | 内容 |
|------|------|
| **顶部状态条**（蓝底白字） | ● 运行状态 · 访问地址 · 请求/缓存命中/错误计数 · ▶启动 / ■停止 |
| **页签 1 · 服务与地址** | 端口、协议、接口、缓存设置 + ArcMap 连接地址列表（表格，可一键复制） |
| **页签 2 · 密钥管理** | 密钥（tk）列在最前并**完整显示**，双击行可查看/复制完整密钥；含添加/编辑/删除、启停、重置用量、测试密钥 |
| **页签 3 · 底图选择** | 按「**影像地图 / 矢量地图 / 地形地图**」三组勾选，**每组内含底图与对应注记**；带「推荐 / 全选 / 清空」 |
| **页签 4 · 运行日志** | 分级日志，支持清空、导出到文件、暂停滚动 |

> 状态条左侧的圆点：**绿色**表示服务运行中，**灰色**表示已停止；
> 右上角「▶ 启动服务」为绿色、「■ 停止服务」为红色，状态一目了然。

菜单栏提供：**文件**（保存/导入/导出配置、开机自启、退出）、**帮助**（使用步骤、官网、关于）。

## 二、申请天地图密钥（tk）

1. 打开天地图官网 <https://www.tianditu.gov.cn/> ，注册并登录。
2. 首页下拉找到「开发资源」→「成为开发者 / 控制台」。
3. 点「创建新应用」：
   - 应用名称：随便填，例如 `ArcMap底图`
   - **应用类型：必须选「服务端」**（选浏览器端在 ArcMap 里用不了）
4. 创建成功后复制那串 Key，就是本工具要填的「密钥」。
5. 免费账号每天约 1 万次请求，一般出图够用。

## 三、使用步骤

1. 运行 `天地图加载工具.exe`。
2. **页签 2 · 密钥管理** → 点「＋ 添加」→ 粘贴 Key。
   - 可添加多个密钥；程序按当日用量自动轮换，规避每日限额。
   - 点「⟳ 测试密钥」可立刻验证密钥是否有效、额度是否用完。
3. **页签 3 · 底图选择** → 勾选需要的底图（默认已勾好 4 个常用底图）。
4. **页签 1 · 服务与地址**：
   - **端口**：默认 80。若无管理员权限或端口被占用，点「检测」自动选一个可用的。
   - **协议 / 接口**：保持默认（`http` / `esri`）即可，`esri` 已修正分辨率不会偏移。
   - **仅本机可访问**：默认勾选（推荐）。取消勾选才允许局域网内其它机器连接，
     但那意味着同网段的人都能借用你的密钥配额，请谨慎。
   - **本地缓存**：建议勾选，重复浏览的瓦片直接从本地读取。
5. 点右上角 **▶ 启动服务**，状态变绿「运行中」。
6. 在地址列表里选中一行点「复制选中」（或「复制全部」）。

### 在 ArcMap 中添加（支持 ArcMap 10.2+，已在 10.2.2 / 10.8.2 实测）

1. ArcMap → 菜单「目录 / Catalog」→「GIS 服务器」→ 右键「添加 WMTS 服务器」。
2. URL 粘贴复制的地址，例如 `http://localhost:80/wmts/img_w`。
3. 点「获取图层」，展开能看到分级图层即成功；确定后把图层拖进内容列表。

## 五、缓存说明（存在哪、怎么确认）

「服务与地址」页签的**缓存位置**一行会直接显示缓存的**绝对路径**，旁边有：

| 按钮 | 作用 |
|------|------|
| 打开目录 | 用资源管理器打开缓存目录（目录不可写会明确报错） |
| 刷新统计 | 弹窗显示：目录、已有瓦片张数、占用空间、本次新写入、写入失败次数 |

右侧常驻显示 `已缓存 N 张 / X MB`，每 5 秒自动刷新一次。

**目录结构**：缓存按 `图层/级别/行号/列号.扩展名` 存放，扩展名**按真实图片类型**自动决定
（`.jpg` / `.png`），例如：

```
<cache目录>/
└── img_w/
    └── 3/
        └── 2/
            ├── 3.jpg          ← 瓦片图片（天地图返回 JPEG 就存 .jpg，PNG 就存 .png）
            └── 3.jpg.ctype    ← 记录 Content-Type（兜底用，避免类型推断错误）
```

- 存储的是**天地图返回的原始字节**，没有任何转码/格式转换，所以扩展名不影响使用。
- **旧版 `.tile` 缓存仍能命中**，不需要重新下载。

**路径规则**：
- 填**绝对路径**（如 `D:\tile_cache`）→ 就用这个目录；
- 填**相对路径**（如 `cache`）→ 解析为**程序所在目录**下的 `cache`，
  即 exe 旁边的 `cache\`，界面上会显示成完整绝对路径。

**缓存不会生效的情况**（现在都会明确提示，不再静默失败）：
- 目录不可写（如选到了 `C:\Program Files` 或只读盘）→ 缓存位置一行会**标红**并给出错误；
- 真正写盘失败时，运行日志会输出一行
  `[缓存] ❌ 写入磁盘失败，缓存不会生效：…`（只提示一次，不刷屏）。

### 缓存会自动清理吗？

**默认会**，在「服务与地址」页签的**自动清理**一行设置（0 = 不限制）：

| 设置 | 默认值 | 含义 |
|------|--------|------|
| 超过 … MB | 1024（1 GB） | 缓存总体积超过上限时，**自动删除最旧**的瓦片直到降到上限内 |
| 或超过 … 天 | 30 | 修改时间早于该天数的瓦片会被删除 |
| 「立即清理」 | — | 按上面两个条件立刻清理一次 |
| 「清空全部」 | — | 删除缓存目录下的所有内容（会二次确认） |

**清理时机**：**程序启动时自动执行一次**，其余时间需要手动点「立即清理」。
清理在后台线程进行，不会卡住界面。

> 判定"最旧"用的是文件的**修改时间**。清理顺序是：先删过期的，若仍超体积上限，再按时间从旧到新删。

### 缓存和 ArcMap 自己的缓存是一回事吗？

**不是，两者独立：**

| | 本工具缓存 | ArcMap 自身缓存 |
|---|---|---|
| 位置 | 你设置的目录 | ArcMap 内部临时目录 |
| 是否可配 | 可配（本工具界面） | 不可配，内部行为 |
| 保留时长 | **由上面的清理规则决定，默认永久保留** | 临时，关闭文档/程序后通常释放 |
| 作用 | **跨会话保留**，下次打开同一区域免重新下载 | 仅当前会话内加速显示 |

所以：**不勾选本工具的缓存，ArcMap 仍能显示地图**（它有自己的临时缓存），
但关掉 ArcMap 后就要重新下载。本工具缓存的价值就是**跨会话保留 + 省密钥配额**。

## 六、托盘与后台运行

- 默认**点关闭按钮不会退出**，而是最小化到系统托盘，瓦片服务继续运行。
- 托盘图标：**双击**恢复窗口；**右键**菜单可「显示主界面 / 启动服务 / 停止服务 / 退出」。
- 想直接退出：在「服务与地址」页签**取消勾选**「关闭窗口时最小化到托盘」，
  或用托盘右键菜单的「退出」，或菜单「文件 → 退出」。

> **怎么确认托盘到底有没有生效？**
> 程序启动时会在「运行日志」里写一行结论：
> - 成功：`系统托盘已就绪：点关闭按钮会最小化到托盘，双击图标可恢复。`
> - 失败：`系统托盘不可用（具体原因（Win32 错误码 N））。`
>
> 把日志里那行原因发出来即可定位。

### 托盘图标没显示怎么办？（已内置兜底方案）

**托盘不可用时程序会自动切换成安全模式**，绝不会变成"进程还在但找不到界面"：

1. 自动**取消**「关闭窗口时最小化到托盘」的勾选；
2. 关闭窗口时若服务正在运行，会弹窗让你选：
   - **是** → 最小化到**任务栏**继续运行（不依赖托盘图标）
   - **否** → 停止服务并退出
   - **取消** → 什么都不做

> 用源码运行时（`python tianditu_gui.py`）因为可能没有 `icon.ico`，
> 托盘图标可能不显示但功能正常；**打包成 exe 后图标会正常**。
> 打包时把 `app.ico` 放在同目录，`build.bat` 会自动识别并作为程序/托盘图标。

### 退出时会不会留下后台进程？

**不会。** 退出流程按顺序完整清理，并且有兜底保护：

1. 停止 HTTP 服务（停止接收新请求，主动断开客户端连接与在途上游请求）
2. 停止托盘线程并**等待它真正结束**（移除图标、释放窗口）
3. 销毁主窗口
4. 检查是否还有**残留线程**；若 1 秒内仍未结束，强制终止进程

这样即使 ArcMap 正在批量请求瓦片（线程池满载），点「退出」也不会出现
"窗口没了但任务管理器里还有进程"的情况。

> 注意：Python 的 `concurrent.futures` 在解释器退出时会无条件等待线程池
> worker 结束，即使它们是 daemon 线程，所以这里不能只检查守护线程。

> 如果退出时确实有线程卡住，运行日志会写一行
> `退出时仍有线程未结束：xxx，强制结束进程。`，便于定位。

## 八、常见问题

1. **图层一片空白 / 不出图**
   密钥是否为「服务端」类型？当日额度是否用完？用「测试密钥」快速确认。

2. **提示启动失败、端口被占用**
   点「检测」自动选择可用端口，或手动填 8080 / 12303 等。
   程序在启动前会**真正检测**该端口能否被独占绑定：
   - Windows 上用 `SO_EXCLUSIVEADDRUSE`（系统推荐做法），占用中的端口不会被误判为可用；
   - 同时会先做一次 TCP 连接探测，有程序在监听也能识别出来。
   若端口已被别的程序占用，会弹窗询问是否自动改用其它可用端口。

3. **ArcMap 里地图整体偏移**
   确认「接口」选的是 `esri`（默认），它使用 EPSG:3857 修正过的元数据。

4. **选了缓存目录，但看不到缓存文件**
   先看「服务与地址」页签的**缓存位置**一行，那里显示的是**真实绝对路径**
   （填相对路径时会解析到 exe 所在目录）。点「打开目录」可直接跳过去。
   注意缓存按 `图层/级别/行/列.tile` 分层存放，要进到子目录里才看得到文件。
   若该行标红「不可写」，说明目录没有写权限，换一个即可。
   另外：**只有真正从代理拉取过的瓦片才会被缓存**，没在 ArcMap 里浏览过的区域不会有文件。

5. **界面卡顿**
   v2 已改为「计数器统计」而不是逐条打印瓦片日志，并复用上游连接；
   请确认没有勾选「详细日志」——勾选后 ArcMap 出图时会大量刷屏。

6. **数据安全**
   本工具**不采集、不上传任何信息**：所有网络请求只发往天地图官方服务
   （`*.tianditu.gov.cn`）和本机地址（`localhost`），密钥只保存在本机 `config.json`。
   服务默认只监听 `127.0.0.1`，局域网内其他人无法借用你的密钥。

7. **下载 exe 后 Windows 提示「未知发布者 / 已保护你的电脑」**
   这是 **SmartScreen** 对**未签名新程序**的通用提示，并非检测到病毒。
   可先核对 release 里的 `SHA256SUMS.txt`，再点「更多信息 → 仍要运行」；
   或右键文件 → 属性 → 勾选「解除锁定」。彻底消除需对 exe 做**代码签名**，
   详见项目 README 的「代码签名」一节。
